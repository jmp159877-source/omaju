## 2. 10/19 밤 ~ 10/20 새벽에 한 일

### 새로 만든 것
- **오늘의 몸 한 가지** — '나를 돌보기'의 네 번째 칸. 28가지 주제를 날마다 돌려 쓴다(tools/gen_daily.py `BODY_TOPICS`). 겁주지 않고 병 이름·진단 없이, '오늘 해 볼 것' 한 줄까지. 장 밑줄도 '산 · 운동 · 마음 · 건강'으로 고침.
- **담아 두기** — 코너 글 밑 단추 → 나의 수첩 '담아 둔 것'(js/radio.js 아님, js/app.js `svBar`/`SV_DATA` + js/notebook.js `refreshSaves`). 글을 통째로 베껴 두므로 그날 것이 바뀌어도 남는다. Firestore `saves` 컬렉션, 본인만 읽고 쓴다(firestore.rules).
- **읽어 드려요** — 장 맨 위 진행자 띠(`#rd-g1`) → 누르면 그 장에 오늘 올라온 것을 코너별로 4~5분 읽어 준다. 장 안에서는 이어지고 장을 나가면 멎는다. 아래에 작은 띠(멈춤·다음 코너·닫기). **소리는 언제나 하나만**(js/radio.js `hush()` + capture 단계 `play` 듣기 + playFollow/playFrom 에서 pause 호출).
- **오프닝 옷 돌리기** — `ROUND = 미소1→은채1→한결1→미소2→은채2→한결2`, 엿새 한 바퀴. 빠진 장면은 `shot()` 이 **같은 옷·같은 시간대 안에서** 비슷한 장면으로 메우고, 쓸 파일 목록을 JSON `imgs` 에 담아 준다. js/opening.js 는 그대로 받아 쓴다.

### 고친 것 (찾아서 고친 것들 — 운영자가 지적하기 전)
- **매일 콘텐츠가 통째로 날아가던 버그**: 맨 마지막에 전부를 한 번 더 저장하는 대목에서 `era` 모양 때문에 Firestore 가 거부(`invalid nested entity`) → 그날치 기록 파일이 안 만들어졌다. 한꺼번에 저장을 없애고 **표시만 남기고 내용은 읽어 와서 파일로 뜨게** 바꿨다(`snapshot()`).
- **코너가 다 차 있는 날 기록 파일을 안 남기던 것** — `snapshot()` 을 일찍 끝내는 길에도 넣었다.
- **'몸 한 가지'가 매일 생성 목록에서 빠져 있던 것** — daily.yml 의 기본 ONLY 에 `body` 추가.
- **시사 상식이 사흘 내리 '텍스트힙'** — `recent_quiz_terms()` 로 요 며칠 쓴 말을 프롬프트에 넣어 피하게 했다.
- **읽어 드려요가 없는 내용을 지어내던 것** — 그날 daily JSON 에 운세·한 끼·한 권·시사 상식·문화가 다 없으면 **아예 만들지 않고** 다음 시각에 다시 돈다.

- media 가지를 로컬에서 볼 때는 `git fetch origin '+refs/heads/media:refs/remotes/origin/media'` — 그냥 `git fetch origin media` 로는 remote-tracking 이 갱신되지 않아 "없다"고 착각한다(10/20 한 번 헤맴).
