## 대표가 정한 것 (어기면 다시 만든다)
- **첫 1~2초가 전부**: 음악이 첫 프레임부터(MUSIC_AT), 크고 굵은 제목이 첫 프레임부터 떠 있다(서서히 나타나기 금지).
- **밝고 깨끗하게**: 밝은 사진 표지(잡지 표지처럼 로고 위·굵은 제목 아래), 어두운 배경 금지.
- **색 이름표·알록달록 단추 금지**(파랑·초록·주황·보라 알약 = 촌스럽다). 글씨는 흰색·검정만, 강조는 노랑 한 가지.
- 휴대폰 틀은 **은색**(검은 두꺼운 테두리 금지).
- 문구: '구독료 0원' 금지 → **'매일 아침 새로운 무료 매거진'**. '50대' 같은 나이 금지(그 나이만 온다). '자극적인 영상에 지치셨나요?'는 대표가 갸웃했다 — 물음 대신 우리 쪽 말로.
- **앞세울 것: 시대 공유(AI 시대 · 전기차 시대 · 요즘 여행법)**, 그다음 즐길 거리(운세·놀이·한 끼·한 권·여행·산·전시·음악). 인사 카드는 주인공이 아니다.
- 길이 **35초 안팎**(장면 일곱~여덟, 연재 화면은 5.5초씩 — 제목이 읽히게).
- 목소리 없음 → AI 표시 안 함. 음악은 우리 것(music/morning.mp3).
- 같은 표지 사진을 이틀 내리 쓰지 않는다(img/anbu/a01~a22 중 밝은 것: a05 바다·a07 창가 바다·a01 단풍·a06 초록 들판…).
