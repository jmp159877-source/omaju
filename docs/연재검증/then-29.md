# then-29 타닥타닥 타자기, 당신이 처음 친 글은 무엇이었나요? — 숫자·날짜 대조표 (2026-11-24)

※ 웹 검색으로 찾은 문서를 직접 열어(WebFetch) 연도·사실을 대조했다. 두 곳에서 맞지 않거나 한 곳에서만 확인된 것은 쓰지 않거나 범위로 적었다:
  이원익 타자기 해(1913 위키백과 · 1914 국가기록원·브런치 → '1910년대 초'), 송기주(1929 무렵 개발 · 1934 신문 소개 → '1934년 신문에 소개'),
  표준 자판 1968(국가기록원 '한글 타자기' 쪽) vs 1969(국가기록원 '한글 기계화'·국어생활·브런치 → 1969),
  한글과컴퓨터 설립 해(1989 머니투데이 · 1990 민족문화대백과 → 안 씀), 첫 국산 워드프로세서 '명필' 1983(전자신문 한 곳 → 안 씀),
  타자검정 폐지 1995.9.3(국가기록원 한 곳 → 안 씀), 타자기 생산 중단 1996(브런치 한 곳 → 안 씀).
