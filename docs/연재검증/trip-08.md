## 쓰지 않은 것
- 휴대품 자기부담금 금액(1만 원 등): 두 곳에서 맞는 값을 못 찾음 → '자기부담금'이라는 말만.
- 2013년 금감원 사례의 통원 자기부담금(1만 5천 원 등): 오래된 값 → 뺌.
- 보험다모아 이용자 중 여행자보험 비교 9.4%(2020.11 기준): 한 곳 → 뺌.
- 2023년 출국자 수(약 2,270만): 한 곳만 확인 → 도표에서 뺌.
- 외교부 해외안전여행: 이 편 주제(보험)와 거리가 있어 22편(영사콜센터)으로 미룸.
- 특정 보험사·앱 이름: 쓰지 않음(보험다모아는 협회 비영리 비교 사이트라 이름을 씀).
