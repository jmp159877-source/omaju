## 도표 계산 (오마주 편집실)
- 가로 막대 = 회사·앱이 밝힌 숫자 그대로. 구글 250 = '거의 250'(앱스토어 249), 실시간 통역 70 = '70개 넘는', 파파고 14. 범례에 대략값이라고 밝힘.
- 언어 수와 번역 품질은 다른 이야기라 범례에 한 줄.

## 쓰지 않은 것
- 구글 오프라인 언어 수(59개 등): 2023년 기사·스카이스캐너에만, 2023년 33개 추가 뒤 지금 공식 숫자를 못 찾음 → 뺌.
- 파파고 이미지 번역 '로그인·월 30회' 제한: Seoul Start 한 곳(웹판일 가능성) → 뺌.
- 구글 번역 월 10억 명·월 1조 단어: 글 흐름에 필요 없어 뺌(Google 블로그·아이엔마케팅·Manila Bulletin 세 곳 일치).
- 실시간 통역이 한국에서 지금 켜져 있는지: 공식 안내에 나라 조건이 없고 한국 출시 기사 못 찾음 → '나라·앱 버전에 따라 단추가 안 보일 수 있다'로만.
- 오프라인 실시간 번역(Pixel 9·10·11 한정, 영어 짝 10개): 고객센터 한 곳 → 뺌.
- 딥엘(DeepL) 등 다른 앱: 2023 기사·스카이스캐너뿐이고 여행 기능 최신 확인 어려움 → 두 앱만.
- 파파고 대화 번역에서 마이크를 번갈아 눌러야 한다는 설명: 2023 기사 한 곳, 지금 버전 확인 못 함 → 뺌.
- 앱 버전 노트의 '음성 번역 기능 신설(9월 1일)': 연도·뜻이 불분명 → 뺌.
