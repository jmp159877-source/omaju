## 쓰지 않은 것
- 58면 여권 금액(53,000→55,000원으로 짐작): 제목에서 두 곳 확인 못 해 숫자로 쓰지 않음.
- 자동심사 누적 이용 1억 명(2018): 한 곳(정책브리핑)만 확인 — 본문에서 뺌.
- 미성년자 이용 나이·등록 조건: 바뀐 이력이 있어 지금 기준을 두 곳에서 확인 못 함 → '생각해 볼 점'에서 공식 안내 확인으로만.
- 해외 공항에서 우리 국민이 쓸 수 있는 나라(독일·홍콩 등): 나라별 등록 조건이 달라 확인 못 함 → 일반 안내로만.
- 2012년 가입자 100만 명(YTN): 한 곳만.
