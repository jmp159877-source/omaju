(주의)
- 2025년 연령 비중(도표1)은 '필기 응시자 설문(기초현황)' 기준, 110,316명은 '통계연보' 응시자 기준이다. 통계연보 전체 응시자는 2,290,491명(실기 포함 추정)이라 둘은 모집단이 다르다 — 본문에 110,316명을 '필기'라 쓰지 않았다(SBS 는 '필기'라 적었으나 데일리안·노컷은 그냥 '응시자').
- 2023(12.2%)과 2025(12.9%)는 모두 필기 응시자 기준이지만 앞은 고용부 집계, 뒤는 기초현황 설문이다 → '조금씩이지만 늘고 있다'로만 썼다.
- 고용부 보도 제목은 '상위 10개'지만 원문에 인원이 있는 것은 여섯(산업안전기사 9,616·전기기사 8,148 포함). 도표는 기능사 넷만.
- SBS 2024 기사는 업무능력 향상을 28.16% 로 적었으나 고용부 원문은 23.1% — 어긋나서 이 항목은 본문에서 뺐다.
- 요양보호사 '교육을 마친 뒤 시험'은 제도 일반 안내(교육 이수 → 시험). 시험 방식이 PBT → CBT 로 바뀐 것은 브라보 한 곳이라 쓰지 않았다.
