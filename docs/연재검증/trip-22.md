# trip-22 해외 위급할 때, 영사콜센터 번호 아시나요? — 숫자·사실 대조표 (2026-11-17)

※ 외교부 누리집(mofa.go.kr·0404.go.kr)은 이 작업 공간에서 robots 차단·권한 대기로 직접 읽지 못했다. 외교부 발표를 옮긴 정책브리핑(korea.kr)·언론 보도·외교부 앱 설명·통신사 안내로 대조했다.
※ 도표 숫자(2024년 나라별 사건·사고 피해)는 외교부가 윤후덕 의원실에 낸 '재외국민 사건·사고 피해 현황'을 옮긴 헤럴드경제·아시아경제 두 곳. 전체 1만 7,283은 머니투데이(한정애 의원실 자료, '건')까지 세 곳. Korea Daily(영문, 2025.10.9)는 같은 숫자를 2023년으로 적었으나 나머지 세 곳이 2024년이라 2024년으로 씀.
