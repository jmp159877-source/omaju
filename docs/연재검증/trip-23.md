## 쓰지 않은 것
- 구글 지도 위치 공유의 가장 긴 시간(사흘 등): 공식 문서 본문을 직접 확인 못 함 → 뺌.
- 카카오맵 개편 전 최대 시간·이용자 수(1,360만 등): 한 곳·제목뿐 → 뺌.
- 아이폰 메시지 '확인(Check In)': 이번에 두 곳 확인 못 함 → 뺌.
