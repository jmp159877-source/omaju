빼거나 낮춘 것
- 2025년 합격률(필기 37.8%·실기 71.9%)은 인비원 한 곳뿐이라 도표에서 뺐다. 2019년(31.2%)은 세 곳이 맞지만 다섯 해로 맞추려 뺐다.
- 누적 취득자 약 42만 명, 전기기사 연봉 숫자(윈스펙)는 한 곳뿐이고 수입 이야기라 쓰지 않았다.
- 양성교육 20시간(산업일보 2015)은 지금도 같은지 두 번째 출처가 없어 시간은 쓰지 않았다.
- 감전 재해 통계는 원 자료(전기안전공사·노동부)를 열지 못해 숫자 없이 단점에 '감전과 추락'으로만 적었다.
- 스터디가브(studygov) 글의 응시료 '약 17,000원·25,000원'은 다른 곳과 달라 따르지 않았다.
- 2026년 4회 실기 날짜(11.14~12.2)는 한 곳뿐이라 본문에 날짜로 쓰지 않았다.
