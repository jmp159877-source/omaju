빼거나 낮춘 것
- 연도별 합격률 표(인비원 2020~2025)는 큐넷 원표와 직접 대조하지 못했고, 이코노미스트 범위(35~45%)와 엇갈려 도표·숫자로 쓰지 않았다.
- 굴착기 실기 시간(인비원 '약 6분')은 한 곳뿐이라 뺐다. 굴착기 응시료도 확인 못 해 뺐다.
- 3톤 미만 굴착기 면허에 필요한 운전면허 종류는 출처가 엇갈릴 수 있어 쓰지 않았다(지게차만 1종 보통).
- 전동지게차 규칙 개정의 시행일은 확인 못 해 쓰지 않았다.
- 채용공고 가운데 지게차 우대 13.4%(SBS Biz 2024.11.28)는 두 번째 출처를 찾지 못해 뺐다. 수입 이야기는 원칙대로 쓰지 않았다.
