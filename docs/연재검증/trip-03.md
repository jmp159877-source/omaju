## 뺀 것 (확인 못 함)
- **'카드 해외 사용액에 해외 직구·앱 결제가 들어 있다'**: 한은 설명을 옮긴 곳이 헤럴드K 한 곳 → legend·생각해 볼 점에서 뺌.
- **2024년 체크카드 해외 사용액**: 직접 적은 보도를 못 찾음(15.7%에서 거꾸로 셈하면 추정) → 도표에 넣지 않음.
- **2023년 사용액 192억 2천만 달러**: 뉴데일리 한 곳(2018년 값과 같아 헷갈림) → 도표에서 뺌.
- **트래블카드 가입자·점유율(트래블로그 1,117만 명·42.3%, SOL트래블 31.0% 등)**: 출처 표기 없는 한 곳(데일리안), 특정 상품 홍보로 보일 수 있음 → 뺌. 상품 이름도 본문에 쓰지 않음.
- **분실 신고 60일 전까지 신용카드 부정사용 보상, 한 카드사에 신고하면 일괄 분실 처리, 긴급 대체 카드**: 한 곳씩만 확인 → 뺌.
- **신용카드 해외 이용 수수료(국제 브랜드·카드사 수수료율)**: 카드사마다 다르고 공식 두 곳 대조를 못 함 → 뺌.
