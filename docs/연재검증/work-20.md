## 뺀 것
- 수습 3개월 최저임금 10% 감액(1년 이상 계약·단순노무 제외 조건) — 이번에 두 곳 대조 못 함
- 5인 미만 사업장 적용 제외 조항 — 대조 못 함
- 국민연금 임의계속가입(60~65세 신청) — 다음 편(21 연금 받으며 일할 때)으로 넘김
- 최저임금 산입범위(식대·교통비) — 단점에 '확인하라'로만
- 2024년 이전 최저임금 — 원 자료로 확인 못 해 도표는 2025~2027만
