## 쓰지 않은 것
- 더포크 '12개국 5만 5천 식당': Paris Match 한 곳만 → 뺌.
- 일본 노쇼가 예약의 약 1%·전날 취소 포함 6%: トラベルボイス 한 곳만 → 뺌.
- 일본 보고서의 '자리만 예약 = 평균 객단가의 50%'(プレジデント) vs '50~70%'(トラベルボイス): 엇갈림 → 뺌.
- Resy 취소 수수료 주 단위 청구 등: 아멕스 회원 전용 안내라 일반 여행자와 거리 멂 → 뺌.
- 구글 예약 단추의 우리말 화면 이름: 공식에서 확인 못 함 → 영어 이름에 '(테이블 예약)'만 덧붙임.
- 오픈테이블 '15분 늦으면 노쇼': Tasting Table 한 곳만 → 뺌.
