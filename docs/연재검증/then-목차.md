# 「그때 그 물건, 지금은」 30편 목차 (초안, 2026-10-27)

원칙: 한 편 = 물건 하나 → 그때의 장면 → 숫자로 보면(도표 하나 이상, 두 출처) → 지금은 → 생각해 볼 점 → 오늘의 물음.
제목은 독자에게 말을 거는 꼴(20~34자). 숫자 후보는 '자료 찾을 곳'에 적었지만 **쓰기 전에 반드시 두 곳 이상 다시 대조**한다.
Commons 검색어는 영어가 잘 걸린다. CC0·PD·CC BY·CC BY-SA만.
