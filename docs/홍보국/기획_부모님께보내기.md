# 홍보국 기획 — "부모님께 보내 드리는 아침 잡지" (2026-10-25)

대표 지시(10/25 16:18): 젊은 층(자녀)이 보고 "괜찮네" → 엄마·아빠에게 카톡으로 바로 보내게. 무엇을 올리느냐보다 **어떻게 구성하느냐**.

## 한 줄 전략
자녀는 **결정하는 사람**, 부모님은 **매일 보는 사람**. 자녀에게는 "효도 한 번, 링크 하나"로 말을 걸고, 누르면 **3초 안에 엄마·아빠에게 카톡이 간다.**

## 흐름 (모든 채널 공통)
1. 첫 1초 그림·글귀로 멈추게 한다 (썸네일·첫 장면)
2. 15초 안에 "무료 · 매일 아침 새로 · 부모님 맞춤"을 화면으로 보여 준다
3. 끝 장면·고정 댓글·소개란 링크 → **omaju.kr/p** (부모님께 보내기 쪽)
4. 그 쪽에서 '엄마에게 보내기' '아빠에게 보내기' 한 번 → 카톡 열림, 문구·그림 미리 채워짐
5. 부모님은 카톡에서 눌러 바로 열람 (가입 없음) → 마음에 들면 홈 화면에 추가
6. 숫자: ?from=kid (자녀 쪽 방문) · ?from=kid_send (부모님이 받은 링크로 들어옴)

## 1. 부모님께 보내기 쪽 (omaju.kr/p) — 클국장이 만든다
- 맨 위: 소개 배너 그대로 — "매일 아침, 새로 나오는 잡지." / 손글씨 "당신의 오늘과 내일, 한 스푼의 보탬이 되는 시간." + 작은 금빛 띠 **무료 · 가입 없이 · 매일 아침 새로**
- 둘째: 휴대폰 화면 석 장이 옆으로 넘어감 — 오늘의 인사 카드 · 오늘의 운세 · 진행자 오프닝 (실제 화면을 찍어 휴대폰 틀에 넣음)
- 셋째: 큰 단추 둘 **엄마에게 보내기 · 아빠에게 보내기** (+작게 '링크 복사')
  - 카톡 미리보기: 오늘의 인사 카드 그림 + "엄마, 아침마다 이거 한번 봐 봐. 운세랑 요리, 옛날 노래도 나와. 공짜야." + 단추 '오늘 호 펼쳐 보기'
- 넷째: "부모님 폰에 깔아 드리는 법" 세 컷 (링크 열기 → 점 세 개 → 홈 화면에 추가)
- 끝: "오마주 매거진 — 오늘도 마음은 주니어" · 네이버·구글에서 "오마주 매거진"

## 2. 쇼츠 '자녀 편' (하루 한 편, 유튜브 → 인스타 릴스·틱톡에 같은 영상)
첫 장면 규칙: **큰 두 줄 글귀 + 휴대폰 화면 한 장**, 사람 얼굴·연기 없음, 지어낸 후기 없음. 끝 장면은 언제나 "댓글 링크 → 엄마·아빠에게 바로 보내기".
돌아가며 쓰는 세 가지 틀:
- A. **"엄마가 보내는 아침 인사 이미지, 이제 이걸로"** — 오늘 인사 카드 4장이 넘어감 → "매일 새 카드, 날짜까지 들어가요"
- B. **"부모님 폰에 깔아 드릴 무료 앱 하나"** — 운세 → 오늘의 한 끼 → 그 시절 노래 → 진행자 오프닝 (화면 녹화)
- C. **"아침 7시, 부모님께 이게 도착합니다"** — 오늘 호를 위에서 아래로 훑기 + 오늘의 운세 한 줄
- 고정 댓글(자동): "👉 엄마·아빠에게 바로 보내기: omaju.kr/p?from=yt" (고정은 대표가 앱에서 한 번 누름)
- 설명란 첫 줄도 같은 링크. 해시태그: #효도 #부모님선물 #부모님앱 #아침인사 #오마주매거진

## 3. 채널별 링크 사정
- 유튜브: 댓글·설명란 링크 눌림 → 가장 짧은 길.
- 인스타그램: 릴스 글에는 링크가 안 눌림 → 프로필 링크 + 스토리 링크 스티커. 글에는 "프로필 링크에서 바로 보내기".
- 틱톡: 프로필 링크는 비즈니스 계정이면 바로(아니면 팔로워 조건) → 처음부터 비즈니스 계정으로 연다.
- 스레드: 글 속 링크 눌림 → "부모님 폰에 깔아 드린 것 중 제일 잘 쓰시는 앱" 같은 이야기 글 + 링크.
